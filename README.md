# Парсер расписания ГУАП в Google Календарь
Скрипт на Python для автоматического парсинга расписания занятий Санкт-Петербургского государственного университета аэрокосмического приборостроения (ГУАП) и его конвертации в формат .ics. Готовый файл можно импортировать в Google Календарь, Apple Calendar или любой другой поддерживаемый сервис.

## Особенности
* Умная обработка недель: Автоматически распознает верхнюю (1) и нижнюю (2) недели, задавая правильные интервалы повторений (rrule) на весь семестр вперед.

* Защита от часовых поясов: Жесткая привязка к московскому времени (Europe/Moscow) через модуль zoneinfo. Пары не сместятся на 2 часа, даже если системное время или аккаунт настроены на другой регион.

* Умные уведомления: Автоматически добавляет будильник (за 45 минут) только для первой пары каждого учебного дня.

* Один файл для всего семестра: Не нужно генерировать расписание каждую неделю — скрипт собирает монолитный файл schedule.ics сразу до конца года.

## Стек технологий
* Python 3.9+
* requests — для загрузки HTML-страницы.
* BeautifulSoup4 — для парсинга DOM-структуры сайта.
* icalendar — для формирования валидного файла .ics.

## Установка и запуск
1. Клонируйте репозиторий на свой компьютер:
```python
git clone https://github.com/ВАШ_НИК/parser.git
cd parser
```
2. Создайте и активируйте виртуальное окружение:
```python
python -m venv .venv
# Для Windows:
.venv\Scripts\activate
# Для macOS/Linux:
source .venv/bin/activate
```
3. Установите необходимые зависимости. Если у вас еще нет файла requirements.txt, установите библиотеки вручную:
```python
pip install requests beautifulsoup4 icalendar
```
(Рекомендуется сохранить их после установки командой pip freeze > requirements.txt)
4. Запустите скрипт:
```python
python app.py
```
После успешного выполнения в папке проекта появится файл schedule.ics

## Импорт в Google Календарь
1. Откройте Google Календарь на компьютере.
2. В левом меню рядом с разделом «Другие календари» нажмите на + $\to$ Создать календарь (рекомендуется создать отдельный календарь для учебы, чтобы пары не смешивались с личными делами).
3. Перейдите в раздел Импорт и экспорт (в левом меню настроек).Выберите сгенерированный файл schedule.ics.
4. В выпадающем списке выберите созданный учебный календарь и нажмите Импорт.

## Настройка под другую группу
По умолчанию скрипт настроен на группу 7852. Чтобы использовать его для другой группы, достаточно изменить URL-адрес в самом низу файла app.py:

```python
url = "https://guap.ru/rasp?gr=ВАШ_НОМЕР_ГРУППЫ"
```
